# Seoul och Tokyo · Resekartan

This GitHub Pages site retains its existing encrypted code gate and original logistics/checklists. The map and day plan use the shared code and encrypted common dataset from the sibling `resplan-japan-sydkorea-2026` repository. Changes to common places therefore reach both websites on reload.

See [the shared project's maintenance instructions](https://github.com/khaaledhamada/resplan-japan-sydkorea-2026#readme) for editing place records. This site's encrypted configuration only includes the shared dataset key; the longer trip's extension is not included.
